GPT-2 in the browser

GPT-2 124M running entirely on this machine, in WebAssembly. The engine is hand-written C++, checked layer by layer against a PyTorch reference, compiled to wasm SIMD. Nothing leaves the page.

Temperature 0 is greedy decoding, the mode the engine is validated in against the reference. Weights: int8-wte-o8, 129 MB, int8 with eight columns of the embedding kept in fp32. Single-threaded. After the first visit the weights load from this browser's cache.
